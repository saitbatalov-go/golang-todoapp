## 🛠 Технологический стек

### Core

| Технология   | Назначение                            |
| ------------ | ------------------------------------- |
| **Go 1.26**  | Основной язык разработки              |
| **pgx**      | Драйвер PostgreSQL с пулом соединений |
| **go-redis** | Клиент для Redis                      |
| **Sarama**   | Клиент для Kafka/Redpanda             |

### Инфраструктура

| Технология         | Назначение                                                  |
| ------------------ | ----------------------------------------------------------- |
| **PostgreSQL 17**  | Основное хранилище данных                                   |
| **Redis 8.6**      | Кеш для ускорения GET запросов (TTL 5 минут)                |
| **Redpanda**       | Kafka-совместимый брокер событий (легковесная альтернатива) |
| **Docker Compose** | Оркестрация всех сервисов                                   |

### Мониторинг и документация

| Технология           | Назначение                           |
| -------------------- | ------------------------------------ |
| **Swagger/OpenAPI**  | Автоматическая документация API      |
| **Zap**              | Структурированное логирование        |
| **Redpanda Console** | Web UI для просмотра Kafka сообщений |

## 📊 Производительность

### Результаты нагрузочного тестирования (10,000 задач в БД)

| Метрика                  | С Redis кешем | Без Redis кеша | Ускорение |
| ------------------------ | ------------- | -------------- | --------- |
| **Requests per second**  | 110.52        | 31.57          | **3.5x**  |
| **Среднее время ответа** | 90.48 ms      | 316.77 ms      | **3.5x**  |
| **95-й перцентиль**      | 108 ms        | 301 ms         | **2.8x**  |
| **Максимальное время**   | 277 ms        | 3595 ms        | **13x**   |
| **Эффективность кеша**   | 99.8%         | —              | —         |

### Запуск тестов производительности

```bash
# Тестирование с Redis кешем
ab -n 1000 -c 10 http://localhost:5050/api/v1/tasks

# Результат: 110.52 requests/sec, 90.48 ms mean
```
